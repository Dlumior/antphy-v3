Este informe describe el modelo y el algoritmo de antphy-v3, un motor de ruteo para la
distribución de suministros en situaciones de emergencia. La urgencia de cada punto se
calcula a partir de un \emph{escenario} configurable (pandemia, terremoto, Fenómeno El Niño)
y penaliza el tiempo de espera según una forma propia de cada desastre. \todo{completar con
